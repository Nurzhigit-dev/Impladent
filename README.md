# Impladent — сайт стоматологической клиники

Одностраничный сайт клиники **Impladent** (Уральск, Западно-Казахстанская область).
Работает с 2011 года. Профиль — имплантация All-on-4/6, хирургия, протезирование,
ортодонтия, терапия и детская стоматология.

Статический сайт: чистый HTML, CSS и JavaScript, без сборки и зависимостей.
Достаточно открыть `index.html` или положить папку на любой статический хостинг.

## Структура

```
index.html              вся разметка страницы
assets/css/style.css    стили, mobile-first
assets/js/main.js       меню, панель действий, биографии врачей, появление секций
assets/img/             логотип, favicon, OG-картинка, фото команды
assets/img/doctors/     портреты врачей
source-photos/          исходники (не попадают в git, см. .gitignore)
```

## Локальный запуск

```bash
python -m http.server 5178 --directory .
```

Затем открыть <http://localhost:5178>.

## Дизайн

Палитра снята пипеткой с фирменного логотипа: золото `#B08050…#E0B070` на почти
чёрном `#101010`.

| Токен | Значение | Где используется |
|---|---|---|
| `--gold` | `#C79A5B` | акценты **только на тёмном** — 7.5:1 на `--ink` |
| `--gold-deep` | `#8A5A22` | акценты **только на светлом** — 5.5:1 на `--bg` |
| `--ink` | `#0E0E11` | тёмные секции |
| `--bg` | `#FAF8F5` | светлые секции |

Шрифты — Playfair Display (заголовки секций, имена врачей, названия направлений)
и Manrope (текст и служебные заголовки). Оба с полной поддержкой кириллицы.

## Что проверено

- Ширины 375 / 768 / 1024 / 1280 / 1440 / 1920 — горизонтальной прокрутки нет
- Заголовок первого экрана держится в три строки на всех ширинах
- Иерархия заголовков без пропусков уровней, один `h1`
- Область нажатия у ссылок и кнопок — не меньше 44px
- `prefers-reduced-motion` — весь контент виден, анимации отключаются
- Без JavaScript контент остаётся видимым (анимации появления включает класс `.js`)
- Мобильное меню, нижняя панель действий и раскрытие биографий врачей

   Если карта не загрузится, под ней показывается адрес и кнопка маршрута в 2GIS.
2. **Телефон.** `+7 777 075 45 03` взят из ссылки `wa.me/77770754503` и используется
   и для WhatsApp, и для звонка. Если для звонков есть отдельный городской номер —
   его стоит добавить.
3. **Часы работы.** Пн–Пт 09:00–18:00, Сб 08:00–13:00, воскресенье — выходной.
4. **Ссылка `canonical`** в `<head>` указывает на GitHub Pages. При переезде на
   собственный домен её нужно поменять.
